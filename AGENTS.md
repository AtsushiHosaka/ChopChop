# ChopChop repository instructions

Before starting work, read [Docs/AgentWorkflow.md](Docs/AgentWorkflow.md),
[DEVELOPMENT_RULES.md](DEVELOPMENT_RULES.md), and the specifications relevant to
the task. The issue workflow applies equally to Codex and Claude.

Keep Demo and Production work and verification separate, as required by
`DEVELOPMENT_RULES.md`. Do not mark real-device or production requirements done
from a demo, compilation result, or mock test alone.

Preserve other agents' and the user's uncommitted work. Record ownership and
scope on the shared Issue before editing; coordinate overlapping files. Reuse
existing applications and containers where possible.
